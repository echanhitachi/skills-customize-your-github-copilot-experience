
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build the classic Hangman word-guessing game using Python strings, loops, and user input.

## 📝 Tasks

### 🛠️	Build the Core Game Loop

#### Description
Create a Hangman game where players guess letters to reveal a hidden word before running out of attempts.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list
- Accept letter guesses and show current progress (e.g. `_ _ _` format)
- Track incorrect guesses remaining
- End when the word is guessed or attempts are exhausted
- Display win/lose messages
